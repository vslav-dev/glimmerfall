# Лёд: сначала площадь, потом толщина (27.11.2026)

## Задача
- Лёд заполняет поле от нуля до целого поля одинарным слоем.
- Второй слой появляется только поверх полностью покрытого поля.
- Двойная шахматка на непокрытом поле недопустима. Одинарная шахматка и двойная поверх полного поля допустимы.
- Количество льда зависит от номера уровня, темпа и силы игрока. Баланс не должен уехать.

## Как было
- Раскладка: один из 5 узоров (центр, низ, рамка, шахматка, боковые колонки). Площадь задавалась долей, зависящей от номера и длины уровня.
- Полное поле давал только центральный узор, и только поздно (около 50+ при обычном темпе).
- Толстый лёд: с 40-го уровня, только во внутренних клетках, по вероятности от стиля игрока.
- Подгонка длины: уровень короче нужного — утолщался весь положенный лёд, площадь не росла. Уровень длиннее — слой тоньше, потом убирались нижние ряды.
- Итог базового прогона баланса: двойной лёд на 25–45% поля на уровнях 8, 11, 14, 15, 17, 21, 41, 45.

## Подход
- Лёд — одно число: сколько слоёв лежит на поле.
- Порядок укладки на раскладку: каждая свободная клетка один раз по одному узору, затем каждая ещё раз по другому (может совпасть).
- Узоры стали порядками роста, каждый доходит до целого поля: прямоугольник из центра, ряды снизу, кольца от стен, шахматка и затем промежутки, колонки от стен.
- N слоёв = первые N записей порядка. Двойной слой до полного покрытия невозможен по построению.
- Срез между клеткой и её зеркальной парой берёт обе: симметричный узор остаётся симметричным.
- Вводный уровень льда: только первый проход, двойного льда нет.
- Стартовое число слоёв: доля свободных клеток, растёт с длиной уровня (темп игрока) и медленно с номером.
- Подгонка длины: число слоёв умножается на отношение нужной длины к длине двойника, как у сбора цвета. Сила и стиль игрока входят через двойника.
- Ящики не меняются: лёд не кладётся под ящики, свободные клетки — без них.
- Версия генератора 13.

## Проверка баланса (средний двойник, уровни с целью «лёд», 3 набора сидов)
- До: победы 0.70 при прогнозе 0.67, 3★ на победу 0.20.
- После: 0.67 / 0.67, 0.67 / 0.68, 0.69 / 0.68; ходов в среднем 29.5–31.2 (было 29.5); 3★ на победу 0.13–0.15.
- Площадь льда: 0.39–1.0 поля вместо 0.24–0.58; двойной лёд только на полностью покрытых полях (8, 41, 57).
- Вся кривая: 0.69 при прогнозе 0.69.
