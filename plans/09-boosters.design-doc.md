# Переносимые бонусы: Падающая звезда и Метеорит (22.11.2026)

## Задача
- Два редких прицельных бонуса, копятся между уровнями.
- **Падающая звезда** — за сэкономленные ходы (ходы, оставшиеся при победе). Копится до 3 штук.
  - Удар: выбранная клетка и 4 соседние, по одному слою каждой. Наследник искры, только прицельный.
- **Метеорит** — за победы на 3 звезды. Максимум 1.
  - Удар: квадрат 5×5 без углов (21 клетка), между бомбой (9) и двойной бомбой (25).
  - Главное: в зоне ломаются **все слои сразу** (цепь, ящик, лёд целиком). Спецфишки в зоне зажигаются и потом срабатывают по одной.
- Квадрат 2×2 больше не матч. Квадрат с хвостом (5 фишек, квадрат + линия) — матч, даёт бомбу.
- Искра как спецфишка удаляется целиком: её прицельность и есть звезда, только редкая.
- Поле выше, под ним справа — две кнопки бонусов с видимым заполнением, без цифр.

## Как сейчас
- Матчи: линии 3+, квадрат 2×2 → искра, L/T → бомба, 4 → линия, 5 → призма.
- Искра летит к самой нужной целям клетке (оценщик целей), комбо искры с линией/бомбой/искрой.
- Бот-двойник калибрует уровни; игрок учится как набор весов признаков хода (в т. ч. «искра»).
- Запись попытки — упакованные ходы; повтор восстанавливает партию.
- Финал превращает оставшиеся ходы в линии; ходы при победе никуда больше не идут.

## Подход

### Правила матчей
- Матч есть только при линии 3+. Квадраты, касающиеся клеток линии, присоединяются к группе.
- Тип спецфишки: 5+ → призма; пересечение линий → бомба; 4 → линия; есть квадрат → бомба.
- Заливка доски больше не избегает квадратов.
- Локальный скан для бота: линии через сдвинутую клетку + квадраты, касающиеся клеток группы, — точное совпадение с полным поиском.

### Удары бонусов в ядре
- Удар — действие игрока, как обмен: ждёт следующего шага доски. Ход не тратит.
- Только на спокойной доске (ни каскада, ни ждущего хода).
- Шаг удара: один взрыв нового вида (звезда/метеорит) в выбранной клетке, затем обычная досыпка и каскад.
- Метеорит: свой «удар насквозь» по клетке — все слои, фишка; спецфишка зажигается.
- Запас бонусов хранит сохранение, не состояние уровня: ядро только применяет удар и считает число ударов попытки.

### Заряды
- Одно число на бонус: накопленный заряд в своих единицах.
  - Звезда: ходы; 1 звезда = 20 ходов; потолок 3 звезды. (Изменено на 40 — см. «Баланс».)
  - Метеорит: победы на 3 звезды; 1 метеорит = 3 таких победы; потолок 1.
- Сверх потолка заряд не копится.
- Начисление — при победе; на экране — сразу, как только победа/третья звезда наступили, ещё до финала.

### Калибровка и обучение
- Бот бонусами не пользуется: уровни калибруются как раньше.
- Победа с бонусом — облегчённая: учит силу игрока с половинным весом.
- Признак «искра» из модели игрока убран; версия модели растёт (модель учится заново).
- Версия генератора растёт: правила матчей другие, уровни пересчитываются.

### Телеметрия
- Удар пишется в поток ходов отдельным флагом: клетка, вид, шаги доски до него. Повтор применяет его в том же месте.
- В сводке попытки — число ударов.

### Сохранение
- Версия сохранения растёт: прогресс, звёзды, настройки, сид и профиль остаются; уровень в процессе начинается заново (на нём могли быть искры).
- Новое поле — заряды бонусов.

### Интерфейс
- Под полем, по правому краю поля, две круглые кнопки: звезда и метеорит.
- Иконки SVG: золотая звезда со шлейфом; раскалённый камень с огненным хвостом.
- Заполнение: иконка «наливается» цветом снизу вверх поверх серого силуэта, плавно.
  - Звезда: под кнопкой три точки — сколько звёзд в запасе; налив — прогресс к следующей.
  - Готовый бонус: полный цвет, мягкое свечение и мерцание.
- Прирост: налив поднимается, кнопка вспыхивает; завершённая единица — кольцо-всплеск и звук, налив начинает снова.
- Прицел: тап по кнопке → режим прицела; касание/наведение показывает зону удара на поле; отпускание — удар. Повторный тап — отмена.
- Раскладка: поле центрируется вместе с полосой кнопок, т. е. поднимается.

### Анимации ударов
- Звезда: падает сверху по диагонали, вращаясь, с золотым шлейфом; вспышка, кольцо, искры.
- Метеорит: влетает издалека, растёт, огненный шлейф и искры; белая вспышка, две ударные волны, пыль, отдача соседей, сильная тряска и замирание.
- Пока летит — пауза перед срабатыванием (как сбор силы комбо).

## Баланс (22.11.2026)

### Метод
- Инструмент `src/tools/balance.test.ts` (запуск только с GF_BALANCE=1): 20 уровней по кривой, средний двойник, 40 партий на уровень, 4 набора сидов.
- Те же замеры на коммите до изменений (с искрой) — для сравнения.
- Спасение бонусом: проигранная партия переигрывается, бонус бьёт в лучшую для целей клетку за 2 хода до конца.

### Результаты (среднее по 4 наборам)
- Победы двойника: было 0,69 при прогнозе 0,685; стало 0,675 при 0,68. Калибровка держит кривую сама.
- Ходов на уровень: было ~23,7, стало ~25,2: без прицельной искры цели добираются чуть дольше, генератор добавил ходов.
- Спецфишки на 100 ходов: было линия 28 / бомба 12 / искра 16 / призма 4; стало линия 28 / бомба 26 / призма 4.
  - Почти все бывшие искры стали бомбами: квадрат с хвостом встречается чаще, чем L/T. Бомба больше не редкость.
- 3 звезды: ~17% побед, как было. У живого игрока порог сам подстраивается к 15%.
- Ходов в запасе при победе: было ~4,9, стало ~6,2.
- Спасение проигранной партии: звезда ~36%, метеорит ~57%.

### Решения
- Звезда: 40 ходов вместо 20 — одна на ~7 побед вместо ~3. При 20 она была бы обычным расходником, а не редкостью.
- Метеорит: без изменений — 3 победы на 3 звезды, одна на ~18–20 побед, потолок 1.
- Кривая и звёзды: без правок — калибровка пересчитывает ходы и пороги под новые правила.
- Открытый вопрос: бомба из квадрата с хвостом заметно чаще бомбы из L/T. Если бомба должна остаться редкой — дать этой фигуре другую спецфишку.
