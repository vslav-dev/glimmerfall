# 08. Визуальная сочность — анализ (20.11.2026)

Цель: красивее, сочнее, мощнее ощущение ударов, без потери частоты кадров. Норма: 120 к/с, минимум 90, на Mali-G57 MC2 (dpr 3) и Mali-G52 MC2 (dpr 2).

## Исходное состояние
- Рендер: Pixi 8, WebGL, цикл по требованию, один атлас Canvas 2D (рисуется раз на размер клетки), 2–5 draw calls, CPU кадра ~0.6 мс.
- Эффекты: всплеск частиц (точки + звёздочки, линейная скорость + гравитация), вспышка-glow, кольцо бомбы, луч линии одним спрайтом, точки призмы, звезда искры, приплюснутость при приземлении, всплывающие очки.
- Тряска: только бомба и призма; случайное смещение каждый кадр, без поворота, без направления.
- Сила события на визуал почти не влияет: каскад меняет высоту звука и похвалу, комбо спецфишек рисуется как сумма обычных взрывов.

## Телеметрия: запаса по кадрам нет (данные 15–20.11)
- **Регрессия 0.21.1.** Установленное приложение с `display: fullscreen` на Mali-G57 идёт на **60 Гц** (интервал 17 мс во всех окнах с 11:38). До этого (вкладка + Fullscreen API) — стабильно 8.5 мс = 120 Гц. Chrome даёт высокую частоту только в режиме Fullscreen API. Фикс подсказки «смахните вниз» стоил 120 Гц.
- Mali-G57, 120 Гц: p50 8.5, но p95 часто 17 → ≥5% кадров пропущено.
- Mali-G52, 90 Гц: p95 22.5, 4–6% кадров > 20 мс (двойной кадр).
- CPU рендера p95 ≤ 2.8 мс → пропуски не от JS-логики сцены. Подозреваемые: GPU/композитор (прозрачный холст поверх CSS-градиента, DOM-слои), главный поток (сохранение, шаг каскада), сборка мусора.
- Неизвестно, **в какие моменты** пропуски: окна агрегируются по уровню.

## Как подходят профессионалы
- «Juice it or lose it» (Jonasson, Purho, GDC 2012), «The art of screenshake» (Nijman, 2013): эффект на каждое действие, наслоение мелких эффектов.
- Eiserloh, «Juicing Your Cameras With Math» (GDC 2016): тряска через «травму» 0..1, видимая сила = травма², плавный шум вместо случайных чисел, поворот вместе со смещением, линейное затухание.
- Хитстоп (файтинги, Сакурай): заморозка 2–12 кадров при ударе, длина по важности. Одинаковый хитстоп на всё стирает иерархию.
- Диснеевские принципы: предвосхищение, сжатие-растяжение, перехлёст, разнесение по времени.
- Match-3 третьего поколения (Royal Match, Toon Blast, Candy Crush): короткие, но плотные анимации спецфишек; отдельная постановка для комбо; вибро на каждый матч; каскад можно перебивать ходом (у нас уже есть); собранные фишки летят к цели.

## Принципы для нас
- Одна шкала силы события (каскад, виды взрывов, комбо, число фишек) управляет всем: тряской, хитстопом, частицами, вибро, звуком, похвалой.
- Красота — в атласе: всё, что рисуется заранее, по кадру бесплатно.
- В рантайме только спрайты и трансформации контейнеров. Без фильтров (blur, glow, bloom), без рендер-текстур на кадр, без DOM-анимаций во время игры.
- Бюджет перекрытия: аддитивные спрайты суммарно ≤ ~2 площадей поля одновременно.
- Без постоянной анимации в простое (батарея, нагрев); короткие редкие вспышки допустимы.
- Каждая ступень — с замером по телеметрии до и после.

## Каталог идей

### A. Ощущение удара (только CPU, по кадру ~0)
- Тряска по Eiserloh: травма копится от взрывов, плавный шум, лёгкий поворот поля, направление (линия — вдоль луча, бомба — толчок наружу). Случайная тряска на 120 Гц выглядит как дребезг, шум — как удар.
- Хитстоп: 40–100 мс замедления твинов на бомбе, призме, комбо; длина по силе. Механизм скорости твинов уже есть.
- Толчок поля: масштаб поля 1 → 1.02 → 1 на сильных взрывах.
- Разнесение во времени: фишки в линии/бомбе исчезают по расстоянию от центра (волна), а не разом.
- Отдача соседей: уцелевшие фишки рядом с бомбой отлетают на долю клетки и пружинят назад.
- Белая вспышка фишки (силуэт) на 1–3 кадра перед лопанием.
- Падение: перехлёст с отскоком при приземлении, сжатие волной по столбцу.
- Обмен: предвосхищение (фишки чуть растут), лёгкая дуга.

### B. Частицы (CPU, мало перекрытия)
- Физика: сопротивление воздуха (быстрый разлёт → зависание), кривые размера, цвета (белый → цвет фишки), альфы.
- Вытянутые по скорости искры-штрихи: выглядят динамичнее точек.
- Осколки: фишка раскалывается на 4–6 кусков своей формы и цвета (кадры атласа).
- Мерцающие звёздочки, мягкие клубы для ящиков, щепки для дерева, крошка льда.

### C. Спецфишки и комбо
- Линия: яркое ядро + цветная кайма, две «головы» бегут от центра со шлейфом, фишки гаснут по мере прохода.
- Бомба: ударная волна, вспышка, отдача соседей, тряска по радиусу.
- Призма: молнии-лучи к каждой цели по очереди, цели вспыхивают и лопаются.
- Искра: комета со шлейфом.
- Комбо двух спецфишек: своя постановка (сбор энергии в центре + хитстоп + усиленный взрыв). Сейчас комбо рисуется как сумма обычных взрывов.
- Создание спецфишки: втягивание (есть) + кольцо-волна + вспышка формы.

### D. Арт и цвет (атлас, по кадру бесплатно)
- Фишки: огранка (светлые/тёмные грани), контровой свет, внутреннее свечение, цветная тень вместо чёрной, сочнее насыщенность.
- Спецфишки ярче отличаются: светящиеся полосы, тлеющее ядро бомбы.
- Поле: подложка-панель с рамкой и мягкой внутренней тенью, клетки с фаской.
- Резкость: поле рисуется с разрешением 2 на экране dpr 3 (растянуто ×1.5, мягче DOM). Разрешение 3 — в 2.25× больше пикселей; только после замера запаса.
- Широкий охват (P3): оба телефона sRGB → не даёт ничего.

### E. Эскалация и праздник
- Каскад: с каждым шагом ярче частицы, сильнее тряска, подсветка краёв поля.
- Очки и собранные фишки летят к счёту/цели, счётчик подпрыгивает при прилёте.
- Финал уровня: салют частиц, волна света по полю.

### F. Отклонено
- Bloom и blur-фильтры: многопроходный рендер, на Mali при 120 Гц не влезает.
- Постоянная анимация фишек в простое: рендер 120 к/с без остановки → батарея, нагрев.
- Шейдеры искажения (рябь, шоквейв-рефракция): полноэкранный проход.

## Архитектура эффектов (22.11.2026)
Решение: сразу к эффектам (120 Гц вернули в 0.21.3). Телеметрия по фазам и запас GPU — позже, по данным после выката.

### Слои ответственности
- Ядро сообщает смысл, не картинку: в шаге очистки появляется центр комбо (если ход — комбо двух спецфишек). Больше ядро не меняется.
- Расписание очистки — чистая функция от события очистки: когда срабатывает каждый взрыв, когда исчезает каждая фишка, трескается слой, загорается спецфишка, всплывают очки. Волна идёт от центра взрыва; следующий в цепочке взрыв ждёт, пока до его фишки дойдёт волна; цель искры гибнет, когда долетела звезда. Покрыто тестами.
- Сила события — тоже чистая функция: вид взрыва, его размер, комбо, глубина каскада → одно число. Им управляются тряска, хитстоп, толчок поля, количество частиц.
- Камера — отдельный контейнер между «скольжением» и полем: травма с затуханием, плавный шум (сумма синусов), поворот, пружинный толчок масштаба, центр — середина поля.
- Хитстоп — в сцене: короткое замедление игрового времени; камера и скольжение идут в реальном времени.
- Частицы — пресеты (искры-штрихи, блёстки, осколки, пыль, щепки, ледяная крошка): сопротивление воздуха, кривые размера и альфы, переход цвета от белого к цвету фишки, вытягивание по скорости. Два слоя: обычный (осколки, щепки) и аддитивный (свет), чтобы не рвать батчи.
- Постановки взрывов (линия, бомба, призма, искра, комбо, создание спецфишки) — отдельный модуль, получает от поля только набор инструментов: координаты, кадры, слои, частицы, камеру, отложенный вызов.
- Пул спрайтов эффектов: без создания и уничтожения объектов на каждый взрыв → меньше сборки мусора → меньше рывков.

### Переключатели
- Каждый эффект — именованный переключатель; выключенный просто не играет. Новый эффект = новая запись + её постановка.
- Отладочное меню в настройках «Эффекты», как подбор звуков: включить/выключить каждый, сразу видно в игре. Выбор хранится в сохранении.

### Вкус
- Иерархия: обычный матч — без тряски; линия — едва заметно; бомба — ощутимо; комбо и двойная призма — сильно + хитстоп. Видимая тряска = квадрат травмы → мелочь почти не трясёт.
- Свет — от белого к цвету: ярко, но без кислотной каши.
- Каждая фишка лопается именно тогда, когда до неё дошёл луч/волна/молния: эффекты и игра совпадают по времени.
- Аддитивного света мало и коротко; перекрытие ограничено.

## Удар нарастает по ходу хода (22.11.2026)

Заменяет силу удара от типа взрыва для тряски, панча и хитстопа: разброс «то мало, то много» мешал.

- Каждый взрыв бонуса бьёт одинаково, сила растёт с номером удара в ходе: crescendo вместо случайных пиков.
- Тряска: еле заметная на первом ударе, +25% на каждый следующий; близкие удары складываются (линейная, затухание медленнее).
- Панч: на каждом ударе, с крошечного и растёт до потолка.
- Хитстоп: только с 5-го удара хода, длиннее с каждым следующим; не чаще раза за шаг.
- Комбо двух бонусов = два удара.
- Сила взрыва осталась только для его собственного вида (отдача бомбы).

- ✅ Тряска, панч, хитстоп от неё
